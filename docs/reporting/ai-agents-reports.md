# AI Agents & Apps Reports

AI Agents & Apps reports in Syskit Point provide easy monitoring for AI usage across your tenant, which helps you track the agents and apps that can access your Microsoft 365 data.

These reports can be accessed in the Report Center by selecting the **AI Agents** category in the filter. The following reports are available:

* [AI Agents Reports](../ai-agents-and-apps/reports/ai-agents-reports.md)
  * Agents Inventory
  * Agent Knowledge Sources
  * Agent Tools
  * Agent Topics
  * Agent Activity
  * Agent Configuration Changes
* [Entra Apps Reports](../ai-agents-and-apps/reports/entra-apps-reports.md)
  * Apps Inventory
  * App Activity
  * App Configuration Changes
* [Permissions and Consent Report](../ai-agents-and-apps/reports/permissions-and-consent-report.md)

To complete actions on agents and apps, such as Block, Reassign, and Delete, [take a look at the AI Agents Actions article.](../ai-agents-and-apps/ai-agents-and-apps-actions.md)
